MIDI Learn in Seq66

Seq66 uses three different types of MIDI Learn: Loops, Mute Groups, and Automation. Loops and Mute Groups work by activating MIDI Learn and then having the user click the 32 (normally) buttons in order until all have been assigned. Automation works by clicking a user-interface item supported by Seq66's controls, and then clicking the device's button desired for that action.

MIDI learning starts when the Learn Manager is brought via the Learn menu. It copies the current setup to an internal container; it can be used to reset to the initial state. The internal container is copied to a working container. Any changes made can be cleared, reset, or saved to a 'ctrl' file at exit. The Learn Manager dialog provides for selecting the Learn mode, counting events that have been set, and showing the event to be set next.

The changes, if saved, are copied back to the performer object and take effect immediately.

Note that the desired MIDI input control device must first be enabled and set as the automation bus in the Edit / Preferences / MIDI Input tab.

Loops Learn

Once set, then, one after the other, click the desired buttons to toggle patterns 0, 1, 2, ... 31. The process stops once the maximum number of grid slots are configured or Reset, Clear, Save, OK are clicked.

Mutes Learn

Similar to loops learn, but applies to the buttons that select mute-groups.

Automation Learn

This mode does not step through a serial list of controls. Instead, the user-interface item must be selected (clicked), show up in the learn manager dialog, and then the desired device control must be clicked. Once clicked, the event is mapped.

See the "MIDI Learn" section of the user manual for more information.
